# Sleep Quality Monitoring Dashboard

A Python-based dashboard to track sleep schedules and monitor sleep quality.

## Features
- Record sleep and wake-up times
- Rate sleep quality
- Add optional notes
- View sleep records and trends

## Technologies Used
- Python
- Streamlit
- Pandas

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install -r requirements.txt`
3. Run the dashboard:
   `streamlit run app.py`
